# Frontend screenshots

These PNGs capture the existing React interface at a 390 × 800 CSS-pixel viewport, with a pixel density of 2, in the light theme.

- `sidebar-idle.png`: initial screen.
- `sidebar-history.png`: menu opened to the bundled fictional history.
- `sidebar-results.png`: the first fictional history item, with its alert expanded.

To refresh them, run the frontend locally, use a fresh browser profile, and follow the steps above. Wait for fonts and entrance animations to finish before capturing. Do not use real patient records. These images illustrate the UI, not the accuracy of a live model response.
